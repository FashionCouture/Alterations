# Montgomery Fashion Design

Tarjeta digital publica para Montgomery Fashion Design, lista para publicarse con GitHub Pages.

## Publicar en GitHub Pages

1. Sube todos los archivos de esta carpeta a un repositorio nuevo.
2. En GitHub, abre `Settings > Pages`.
3. En `Build and deployment`, elige `Deploy from a branch`.
4. Selecciona la rama `main` y la carpeta `/root`.
5. Guarda y espera a que GitHub genere la URL publica.

## Ajuste importante

El HTML esta preparado con esta URL:

`https://fashioncouture.github.io/Alterations/`

Si el repositorio o usuario de GitHub tiene otro nombre, actualiza en `index.html` las etiquetas `canonical`, `og:url`, `og:image`, `twitter:image` y el bloque `application/ld+json`.
